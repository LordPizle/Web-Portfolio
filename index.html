Dishcovery

AI Restaurant Discovery Web App

Dishcovery is an AI-enhanced restaurant discovery web application designed to help users find restaurants that better match what they actually want to eat. Instead of only relying on basic keyword search, the app uses TF-IDF and cosine similarity to improve how restaurant results are ranked.

Testing showed TF-IDF ranking returned more relevant restaurants than keyword-only search across varied meal queries.

Problem solved

Restaurant search results can often feel too broad, irrelevant or difficult to compare. Dishcovery improves this by matching the user's search query more closely with restaurant information.

Key features

  • AI-enhanced restaurant ranking
  • TF-IDF and cosine similarity recommendation logic
  • Google Places API integration for live restaurant data
  • Photon geocoding for location search
  • Haversine distance calculation for nearby results
  • Filters such as open now and minimum rating
  • Sorting by distance, rating and best match
  • Clean responsive user interface
  • Rule-based assistant for user guidance

My contribution

Built the full-stack application, connected APIs, implemented the recommendation logic, designed the frontend and tested the system against keyword-only search.

Patient Observation System

Healthcare Staff Web Application

A secure, staff-facing web application for healthcare teams to register patients, track condition status, log vital-sign observations over time, and review activity from a central dashboard. Built as a single Flask server serving HTML pages with a custom green-and-white interface.

End-to-end Flask app with auth, patient and observation CRUD, dashboard analytics, and in-app notifications in one deployable codebase.

Problem solved

Manual or scattered patient observation records are hard to search, update and review. This system gives staff one place to manage patients, record clinical observations and see recent activity with in-app notifications.

Key features

  • Secure authentication with sign up, sign in and password reset
  • Staff and admin roles with session-based access control
  • Full patient management with filter, sort, profile and cascade delete
  • Observation tracking for vitals (BP, heart rate, temperature, SpO2, and more)
  • Dashboard with live search, stat cards and condition breakdown chart
  • In-app notifications with unread badges and mark-as-read
  • Profile management and JSON API endpoints for search and stats
  • Dark mode toggle and responsive custom CSS layout
  • SQLite database with User, Patient, Observation and Notification models

My contribution

Designed and rebuilt the full application: Flask backend, SQLite data models, authentication flow, patient and observation CRUD, dashboard with stats and charts, notification system, API routes, and the complete frontend using HTML, Jinja2, CSS and JavaScript.
